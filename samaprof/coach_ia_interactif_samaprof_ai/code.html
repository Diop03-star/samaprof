En programmation, le symbole = n'est pas une équation d'égalité mathématique. C'est une flèche d'affectation : on calcule toujours d'abord ce qui est à droite (x + 5), puis on range le résultat dans la boîte étiquetée x.

Métaphore visuelle : La boîte Python Étape par étape

2. Nouveau contenu
📦 15
x vaut 15
